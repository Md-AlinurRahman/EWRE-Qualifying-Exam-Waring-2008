# Data

This folder contains tabulated data used to reproduce figures presented in the EWRE Qualifying Exam presentation.

The numerical values were transcribed from tables reported in:

Waring, M. S., Siegel, J. A., & Corsi, R. L. (2008). 
Ultrafine particle removal and generation by portable air cleaners. 
Atmospheric Environment, 42, 5003–5014.

These data are provided for educational analysis and reproducibility of the presentation figures. They are not original experimental data collected by the repository author.

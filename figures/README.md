# Figures

This folder contains figures generated in RStudio for the EWRE Qualifying Exam presentation.

Figures were created using tabulated data reported by Waring et al. (2008).

## Figures

- `Phase1_CADR.png` — comparison of mean size-resolved CADR among air cleaners
- `Phase2_Particle_Size.png` — particle-size ranges with statistically significant net formation
- `Phase2_PM_O3.png` — particle and ozone concentrations across Phase 2 experimental conditions
These figures were created for educational and presentation purposes.
